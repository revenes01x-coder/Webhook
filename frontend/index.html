Access Request

คุณได้รับอนุมัติให้ใช้งานระบบแล้ว

บัญชีของคุณผ่านการตรวจสอบและอนุมัติเรียบร้อยแล้ว ไม่จำเป็นต้องส่งคำขอใหม่อีก
คุณสามารถไปที่เมนู นักพัฒนา (API & Webhooks) ด้านซ้าย เพื่อตั้งค่าการเชื่อมต่อได้ทันที

คำขอของคุณอยู่ระหว่างการพิจารณา กรุณารอ Admin ตรวจสอบก่อน — ระบบจะแจ้งผลไปที่อีเมล บัญชีที่คุณใช้เข้าสู่ระบบ ดูรายละเอียดที่ส่งไปได้จากตาราง "สถานะคำขอของฉัน" ด้านล่าง (กดไอคอนรูปตาที่แถวคำขอนั้น)

ส่งคำขอใหม่

ชื่อผู้ติดต่อต้องเป็นภาษาไทยหรือภาษาอังกฤษเท่านั้น (ห้ามมีตัวเลข/อักขระพิเศษ)
ใช้เป็นข้อมูลติดต่อประสานงานเท่านั้น (เช่น อีเมลของฝ่ายอื่น/ผู้ประสานงาน) — อีเมลแจ้งผลอนุมัติ/ไม่อนุมัติ ระบบจะส่งไปที่อีเมลบัญชีที่คุณใช้เข้าสู่ระบบเสมอ
